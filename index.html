Success engineer

A paste-in tool that cut a 12–15 minute check to 2–3 minutes

The one project here that comes from my real work, described in general terms. The demo is a rebuilt version that runs on made-up data.

The problem

A trader can hold several funded accounts, but only a limited number can be active at once. The others, which have already passed their evaluation, wait on hold. When an active account is lost to a rule breach, support has to confirm which held account is next in line. Doing that meant filtering a long raw data export by hand, every time.

Direct access to the system was not available, so a connected tool was not an option.

What I built

A small web tool. I filter the export down to the few fields that matter, paste it in, and the tool lists the held accounts in order and shows which one is next. Nothing is stored and no system access is needed.

The result

12–15 minutes down to 2–3 minutes per check, and an Excellence Card for the work.

What I took from it

A limit can lead to a better design. Having no access pushed me to a simpler tool with fewer fields, less risk and nothing to maintain.

The AI prompt I would use 
You are helping a support team. Below are 40 support chats with names and account numbers removed.
1. Group them into themes of no more than six.
2. Count the chats in each theme.
3. For each theme, give two short example phrases a client used.
4. Suggest one change the product team could make for each theme.
Only use what is in the chats. If a chat fits two themes, count it under the main one and say so.

AI does the first grouping. I read the chats behind each theme before anything is reported, because a count is only useful if the themes are right.

Knowledge base · FAQ revamp

Rewriting FAQs so people can solve it on the first read

I start from the questions that cause the most tickets, rewrite each answer so it can be read in under a minute, and check it against six simple tests. Both examples below are fictional.

My revamp routine

  1. Pull the top themes from tickets and chats, including the ones behind escalations.
  2. Rewrite the title as the question people actually ask.
  3. Put the answer in the first sentence.
  4. Add numbered steps and say what success looks like.
  5. Say exactly what to send if it still fails.
  6. Ask someone who has not seen it to try it, then compare ticket volume a month later.
